# Ti'Magnet

Magnets Photo Personnalisés & Aimants Frigo France.

## Project info

This project is built with:
- Vite
- TypeScript
- React
- shadcn-ui
- Tailwind CSS

## How to run locally

```sh
# Install dependencies
npm install

# Start development server
npm run dev
```

## Build

```sh
npm run build
```
